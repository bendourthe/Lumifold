# Known Gaps & Platform Constraints -- v0.1.0

This document records architectural boundaries and hardware-level constraints for the Ambient Fold live wallpaper v0.1.0 release.

---

## 1. Hardware Display Power Cutoff (0° to 10°)

- **Constraint**: Google Pixel foldables automatically power down the inner folding display and migrate active focus to the outer cover display once the physical hinge closes past approximately 10° to 15°.
- **Impact**: While `HingeSensorObserver` computes mathematical blur progress continuously down to 0.0° (0° to 180°), the physical screen turns off before the user reaches 0° flat-closed.
- **Mitigation**: The 1.8 power ease-in curve concentrates blur heavily between 90° and 15°, ensuring the depth transition is visually prominent throughout tabletop and near-closed postures before the hardware display cut-off occurs.

---

## 2. Stock Pixel Launcher Layer Decoupling

- **Constraint**: Standard Android Live Wallpapers render within a dedicated window layer (`TYPE_WALLPAPER`) underneath the system launcher.
- **Impact**: When the user folds the device, the wallpaper canvas smoothly blurs and scales by 1.04x. However, app icons, search widgets, and the At a Glance bar remain sharp unless blurred by the launcher's own task-switching shell.
- **Mitigation**: This is an intentional design boundary to preserve the official Google Pixel Launcher experience, gestures, and widgets without requiring a custom home screen replacement.

---

## 3. Emulators without Hinge Sensor Emulation

- **Constraint**: Standard Android phone emulators lack `Sensor.TYPE_HINGE_ANGLE`.
- **Impact**: On non-foldable hardware or generic emulators, `HingeSensorObserver.isSensorAvailable` returns false.
- **Mitigation**: `MainActivity` provides a real-time fold simulation slider (0° to 180°) that directly exercises the ease-in curve and `RenderEffect` blur pipeline for testing.
