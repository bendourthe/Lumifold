# Ambient Fold Documentation

Central documentation tree for the Ambient Fold live wallpaper application.

## Directory Layout

- `releases/`: Per-version release documentation, implementation plans, and comparisons.
  - `v0/v0.1/plans/`: Implementation plans and technical specifications for v0.1.x.
  - `v0/v0.1/comparisons/`: Benchmark and comparative evaluation reports.
- `handbooks/`: Living architectural, design, and developer handbooks.
- `decisions/`: Architecture Decision Records (ADRs).
- `todos.md`: Living progress tracker across development phases.
- `DEVLOG.md`: Chronological release index.
